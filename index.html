You opened index.html directly from your file explorer. Because this is a modern React/Vite web application, browsers block raw TypeScript modules over file:// URLs for security.

How to run in 10 seconds:

Option 1: Open a terminal in this project folder and run:

npm install
npm run dev

Option 2: Double click start.bat (on Windows) or start.sh (on Mac/Linux).

Option 3: If you ran npm run build, serve the dist/ folder or open with VS Code "Live Server".
